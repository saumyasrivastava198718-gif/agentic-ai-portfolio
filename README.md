## Featured Project

### 📄 End-to-End PDF RAG Pipeline

The first completed project builds a Retrieval-Augmented Generation system over Microsoft's annual report.

The pipeline performs:

**PDF → Text Extraction → Chunking → Embeddings → ChromaDB → Semantic Retrieval → Gemini → Grounded Answer + Source Pages**

### Technology Stack

- Python
- PyMuPDF
- Sentence Transformers
- ChromaDB
- Google Gemini API
- Streamlit
- Git
- GitHub

The project includes modular source code, retrieval logic, persistent vector storage, tests, a Streamlit interface and detailed documentation.
