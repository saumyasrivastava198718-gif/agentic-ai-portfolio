# 🎮 Escape the AI Lab — Text-Based Adventure Game

## 📌 Project Overview

Escape the AI Lab is an interactive text-based adventure game built using Python.

The player wakes up inside an abandoned AI research laboratory and must explore different locations, make decisions, manage health, collect a key, and find a way to escape.

This project demonstrates core Python programming concepts and AI-assisted software development practices.

---

## 🎯 Learning Objectives

This project demonstrates:

- Python variables
- Dictionaries and lists
- Functions
- User input
- Conditional statements
- `while` loops
- Control flow
- State management
- String manipulation
- Basic input validation
- Modular program design
- AI-assisted coding concepts
